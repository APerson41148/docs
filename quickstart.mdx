## Prerequisites

Before you begin, you must have:

- VsCode
- Windows 10 or later / MacOS 12 or later / Most Linux OS

## Get started

<Steps>
  <Step title="Install Pygame">
    Pygame is an essential library that I use often for my projects. It is great because it allows keybinds and intuitive window creating. Use the one below if your OS is Windows.

    ```bash
    pip install pygame 
    ```

    Use the one below if your OS is MacOS/Linux.

    ```bash
    pip3 install pygame
    ```

    ```bash
    pip3 install pygame
    ```
  </Step>
  <Step title="Install NiceGUI">
    NiceGUI is an essential library that I use often for my projects because it makes. Use the one below if your OS is Windows

    ```bash
    pip install nicegui
    ```

    Use the one below if your OS is MacOS/Linux

    ```bash
    pip3 install nicegui
    ```
  </Step>
  <Step title="Verify NiceGUI is installed correctly">
    1. Create a new file named `main.py` in your VS Code workspace.
    2. Paste the following minimum working code:

    ```bash
    from nicegui import ui
    
    ui.label('Hello NiceGUI!')
    
    ui.run()
    ```

    3. Run the application from your terminal

    ```bash
    python main.py
    ```

    4. A browser window will automatically open up, or you can manually navigate to `http://localhost:8080` to see your running web app. NiceGUI features hot-reloading, so any changes you save in VS Code will update in the browser instantly.
  </Step>
  <Step title="Verify Pygame is installed correctly">
    Create a new file named `test.py` and paste the following snippet to test if it works:

    ```bash
    import pygame
    
    # Initialize pygame
    pygame.init()
    
    # Print confirmation
    print("Pygame installed successfully!")
    print(f"Version: {pygame.__version__}")
    ```

    Run the file. If you see the version number printed in the terminal without errors, your setup is complete.
  </Step>
</Steps>
